# NVK Agent v0.1.8 — orb node rebuild + retest #4 fixes

2026-11-22. Build + test only; NOT deployed, NOT pushed. Live site is v0.1.7.

## What changed

Owner direction (2026-11-22 ~22:32 PT, approved ~22:34 PT): remove the
legacy gateway links from the Agent orb and replace them with agent
management / system information.

### Node rebuild (approved)

- **Removed:** the four legacy Nexus gateway nodes — The Vision, The
  Codex, The Nexus, The Lore — from `NEXUS_GATEWAYS`
  (`src/experience/orb/vendor/constants.ts`), the canvas nodes and the
  DOM buttons (`CodexOrbSystem.tsx`, `OrbHost.tsx`). Removed with them:
  their MythoTech descriptions, their legacy project lists (keynote,
  omegaLogicCore, nexusReasoningCore, triSophianCodexV2, rebirthProtocol,
  agentCommandCenter, nvkTimeMachine, nvkClothing, headphoneHero,
  fwtPaper, hqidPaper, scrollLawPaper, starbornSynthesis, …), the
  `allProjects` detail map, `SLIDES_DATA`, `LORE_DATA` (all unreferenced
  elsewhere in src/), the `NexusGateway` type, and `ProjectViewer.tsx`
  (deleted — it had nothing to show once the project lists were gone).
  The legacy content survives in repo history (GitHub main).
- **Added:** `NVK_AGENT_NODES` — Agents, Evidence, Diagnostics, System.
  Each node carries the real panel it opens; the host maps node → panel
  directly, with no legacy view-name mapping anymore. Chat and
  Visualizations stay in the nav tabs; they are not orb nodes. The orb
  itself stays NVK (v0.1.7 rename) with Phase A state discipline intact
  (no timers, no canned states — the no-timer tests still pass).
- **Evidence panel (new, real):** `src/experience/chat/EvidencePanel.tsx`
  reads the actual evidence store (`src/sovereign/evidence.ts` — hashed
  records) and lists entries with hashes, route, model, time, and a
  working Re-verify button (recomputes the SHA-256, reports pass/fail).
  Empty store shows "No evidence recorded yet" — never fabricated
  entries. Added to `OrbPanel` and the nav tabs.
- **Kept as the stable seam:** the internal `onGatewaySelect` /
  `handleGatewaySelect` names (the renderer prop the Phase B tests pin)
  and the `userData.type === 'gateway'` node tag — internal identifiers,
  not user-facing copy. The dead vendored `ActiveView` type union in
  `types.ts` was left in place (no consumers, no runtime presence).

### Retest #4 queued fixes (folded in)

- **Label visibility:** nodes now sit in a fixed front arc
  (`src/experience/orb/node-layout.ts` — angles 35°/70°/110°/145°,
  every node z > 0, camera side) and the ring never rotates. The
  far-side label fade is kept for user orbited views. Test asserts the
  geometry directly (all z > 0, x spread across the view).
- **Empty-black panel:** camera starts tilted (0, 10, 22) instead of
  flat (0, 0, 25); Focus (0, 4, 14) and Reset (0, 10, 22) keep the
  tilt. The galaxy disk (radius 20) and node ring now read as an
  ellipse filling the frame instead of a band over black.
- **Below-fold prompts:** desktop orb panel 520px → 420px
  (`src/index.css`); the hero (all four cards + example prompts) fits
  the first screen at 1920×1000.
- **Clear-data fix:** `memoryStore.clearAll()` now deletes the Cache
  API store `transformers-cache` — the only cache the app creates
  (`inference.ts:500`). The confirmed root cause (diagnosis G1): the
  weights never lived in IndexedDB/localStorage, so the old clear left
  ~466.8 MB behind. The confirm dialog is kept.
